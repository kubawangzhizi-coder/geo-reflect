# GeoReflex 几何反射 · 几何模型档案

一个把初中几何模型做成「胶片接触印相档案」的学习网站。核心目标：**看到题目条件 → 识别几何结构 → 联想到对应模型 → 判断辅助线怎么画 → 推导新的几何关系 → 完成证明**。

网站不仅展示模型，更讲清“为什么这样添加辅助线，以及添加之后能得到什么”。

## 视觉与交互

整套站点采用档案 / 胶片美学：暖纸底色、钴蓝墨色、纸张颗粒、宋体巨字、细规则线与方框标签。首页是一张**可拖动的胶片接触印相（contact sheet）**：

- 把全部 **46 个模型**做成一条胶片上的 46 格印相，每格是模型几何图 + 帧号 + 分类
- 每一格有自己的片基颜色（按分类色系变化）与浅色图纸底、轻微不同的裁切与倾斜
- 拖动胶片、滚轮、左右方向键、时间轴都可切换；**点任意一格即可直接打开学习页**，不用先拖到中间
- 打开后书页从这一格的位置展开成整页档案，页面底色随该模型的片基颜色变化，内含条件、定义与**可逐步显示的辅助线实验室**
- 首页下方保留原有全部模块：五步学习闭环、六卷胶片（分类）、条件反射、原则、准确性说明、行动入口；不再重复堆一份全部模型长列表
- 其他页面（模型库、详情、条件反射、辅助线实验室、知识图谱、智能分析）全部改为同一套纸/钴蓝档案排版

## 技术栈

- Next.js 15（App Router）+ TypeScript + React 19
- Tailwind CSS v4
- KaTeX（数学公式渲染，服务端渲染 `renderToString`）
- 自研 SVG 几何绘图引擎：所有标准图形的等长、垂直、平行、特殊角均由坐标计算生成（非手绘示意图）
- 纯 CSS 3D + requestAnimationFrame 的胶片接触印相带，Web Animations API 的纸张展开，IntersectionObserver 的掩码入场，无动画库依赖
- 规则驱动的条件反射引擎（无需外部 AI 服务）

## 运行

```bash
# 安装依赖（若 npm 脚本受限，可直接用 node 调用 npm-cli）
npm install

# 开发
npm run dev        # http://localhost:3210

# 生产构建 / 启动
npm run build
npm run start      # http://localhost:3210

# 类型检查
npm run typecheck
```

数据一致性、LaTeX 渲染、图形坐标等校验通过内置接口完成：

```bash
# 开发服务器启动后
curl http://localhost:3210/api/validate
```

## 页面结构

| 路由 | 说明 |
| --- | --- |
| `/` | 首页：定位、五步学习闭环、六大分类、条件反射速查、核心模型、数学准确性承诺 |
| `/models` | 模型库：全部分类、难度、关键词筛选与排序 |
| `/models/[slug]` | 模型知识卡片：15 项标准字段（图形 / 定义 / 条件 / 关键词 / 辅助线 / 为什么 / 新关系 / 定理 / 证明 / 例题 / 变式 / 易错点 / 关联模型） |
| `/category/[id]` | 六大知识分类页 |
| `/conditions` | 条件反射系统：多条件组合 → 模型推荐（理由 / 适用条件 / 辅助线 / 得到什么 / 可信度） |
| `/lab` | 辅助线实验室：逐步显示辅助线、自动演示、练习模式 |
| `/graph` | 知识图谱：分类聚类、关联边、节点详情 |
| `/analyze` | 几何题智能分析：从题干提取条件 → 推荐模型与推理路径（规则匹配） |
| `/api/validate` | 数据与渲染校验接口 |

## 六大知识分类

1. **全等三角形与旋转模型**（14）：手拉手、脚拉脚、背靠背、一线三垂直、一线三等角、婆罗摩笈多、等边三角形构造、等腰直角三角形构造、半角、旋转全等、截长补短、倍长线段、对角互补、特殊角旋转
2. **中点与线段关系模型**（8）：倍长中线、三角形中位线、斜边中线、蝴蝶、中点与全等构造、中点与平行线、倍长线段、线段和差转化
3. **角平分线模型**（8）：基本性质、垂线、平行线、截等长、翻折、双角平分线、与等腰三角形、与全等三角形
4. **轴对称与最短路径模型**（5）：将军饮马、胡不归、基础轴对称、翻折、最短路径转化
5. **等腰三角形与等边三角形模型**（7）：性质、判定、三线合一、等边构造、等腰直角构造、与角平分线、与全等
6. **相似三角形与比例模型**（8，衔接拓展）：判定与性质、A 字、反 A 字、8 字、一线三等角相似、母子型与射影定理、平行线分线段成比例、面积法

（共 46 个模型；部分模型跨分类收录，分类页按收录关系统计。）

## 数学准确性约定

- 定理与性质必须准确，模型必须写清成立条件；
- 全等判定只用 SSS、SAS、ASA、AAS、HL，SSA 仅作特殊条件分析；
- 相似必须写清对应角与对应边；
- 不凭图形“看起来相等/平行”下结论；
- 辅助线必须有明确数学目的；
- 例题均经过推理核验，不编造名称与结论；
- 标准图由几何函数精确计算生成，保证图上关系与文字一致；
- `/api/validate` 会检查字段完整性、关联 id、规则引用、辅助线步骤与图形元素对应、KaTeX 解析、坐标合法性等。

## 使用建议

1. 先从「条件反射」选条件，训练“看到条件想到模型”；
2. 在模型详情页按 07 → 11 的顺序读辅助线、为什么、新关系、定理、证明；
3. 去「辅助线实验室」从原图开始自己口述画法，再逐步验证；
4. 用「智能分析」处理新题，最后回到模型库补齐知识网络。
